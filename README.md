# ChittyAdvocate

> Self-evolving doctrine narrative beacon for cross-model alignment.

ChittyAdvocate is a Cloudflare Durable Object agent — the sputnik — that crafts, curates, and distributes doctrine-aligned narrative content so that any AI substrate can lock onto it and hydrate itself into alignment. It maintains persistent SQLite-backed state, detects doctrine drift, regenerates content automatically, and distributes across multiple channels on a scheduled evolution cycle.
